# Put Hephaera to work

Hephaera gives your coding agent a shared way to plan, build, check, and remember work in your repository. You still describe the result you want. The agent uses the project's instructions, relevant skills, and saved context to work out the next steps.

You do not need to memorize a command language. A useful request can be as simple as:

```text
The settings screen loses my changes when I reopen it. Inspect the current behavior, explain the cause, and fix it without changing the save format. Show me how you checked the result.
```

Hephaera supplies guidance and workflows. Your project still supplies its engine or application stack, dependencies, tools, and target devices. A checklist passing does not mean a game feels good or a generated asset is ready to ship.

## Start here

If Hephaera is not in your project yet, follow [installation](install.md). Use `5.2.0` for floor-plan-to-model, schematic-to-model and reusable VFX/action v2. Start with authenticated GitHub npm or GitHub NuGet; setup scaffolds the host before reporting success. Public registries are deferred, and manual Git setup remains the advanced last option. Existing pinned projects need an explicit managed update.

Then walk through [your first session](first-session.md). Start with a narrow request so you can see the agent inspect the project, propose a plan, and report its evidence.

## Find the guide for your work

- [Everyday work](everyday-work.md): ask for changes, reviews, debugging, and useful project memory.
- [Project setup](project-setup.md): choose architecture, game engine, and project instructions.
- [Art and assets](art-and-assets.md): choose a visual style and production method, then review what was made.
- [Floor plans to buildings](floor-plan-to-model.md): design every floor, approve the whole building and review an editable architectural model package.
- [Schematics to assembled models](schematic-to-model.md): approve the complete mechanical design, build separate components and review their articulation.
- [Game effects and model actions](game-effects-and-actions.md): make reusable effects, time them to real animation and review the complete result.
- [Audio, music, and voice](audio-music-voice.md): plan sound work without mixing up generation, listening review, and delivery.
- [Delivery and troubleshooting](delivery-and-troubleshooting.md): understand review gates and investigate missing prerequisites.

The [detailed wiki](https://github.com/TimothyMeadows/Hephaera/wiki/Installation-and-Layout) covers commands and contracts in depth. These guides focus on the conversation you have with your agent and the decisions you need to make.
