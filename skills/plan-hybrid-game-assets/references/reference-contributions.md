# Reference contributions and revision intent

## Define the influence

Use existing task notes and source records; this adds no manifest or identity-library format. For each rights-cleared reference, retain its file/hash and intended use. Name the properties it informs, such as silhouette, construction, pose, palette, material response, lighting or camera. One source may inform several properties when the task requires them; unrelated subjects, logos, background objects or incidental colors do not become requirements merely by appearing in it.

Separate required observations, supported inference and unresolved assumptions. Resolve conflicting contributions before authoring: a pose study should not silently replace the selected proportions, and a material sample should not redefine dimensioned construction. Keep STYLE and the selected pipeline authoritative; a reference cannot select a new style or backend.

For a related set, name the features that must remain consistent and the differences requested for each item. Include meaningful asymmetry, handedness, equipment ownership, scale and viewing conditions where relevant. Check both that the requested contribution is present and that unintended content has not transferred. A seed records one supported execution setting; it cannot establish identity across changed prompts, models or tools.

## Preserve the actual workflow

Compare variants against the selected approved baseline under comparable camera, scale and lighting. Preserve every actual parent in an authored edit chain; do not overwrite the baseline or forbid legitimate sequential edits. A changed baseline or complete proof/design package requires the selected workflow's refreshed affected approvals, even if some artifacts are reusable.

References support local planning and authoring through available tools. This record does not add reference-image conditioning, control maps or masked editing to the installed generator. Pass only inputs supported by the admitted tool; missing capability stays unavailable. No service, upload, training or installation is implied.

PROOF_TO_MODEL retains its original-only classification and complete six-view preparation/approval. Do not tighten individual crops, substitute a geometry reference for an original, or treat generated proofs/renders as new evidence of original structure. Floor-plan and schematic dimensions remain explicitly authored in their approved structured designs. A reference's availability grants no modification, reproduction or redistribution rights by itself.

## Review record

Bind each result to its current inputs and requested differences. Record any missing contribution, unintended transfer or unresolved conflict by item and evidence. Keep technical validation, source/design selection, human model acceptance and runtime promotion as their actual separate gates.
