# Lifecycle evidence

Select the claims appropriate to the host's actual profile and retain unsupported/unrun cases visibly.

| Boundary | Evidence |
| --- | --- |
| Contract | Exact compiler/EVM/dependency/source inputs; supply and quantity conservation, unauthorized calls, lifetime issuance, burn/craft and receiver callback behavior |
| Account | Real selected signature semantics, one-use scoped authentication, expiry, contract/counterfactual/delegated account handling, authority changes and revocation |
| Ownership | Exact chain/collection/token/quantity, code/proxy identity, canonical block/hash, freshness, RPC trust and unavailable versus zero |
| Gameplay | Quantity-aware concurrent admission, approved snapshot seller/buyer behavior or actual strict lock/escrow recovery; no claimed lock from a server reservation |
| Trading | Exact terms, allowed payment semantics and integers, actual selected settlement protocol, replay/expiry/fill/cancel, stale approval and competing buyers |
| Recovery | Intent identity before side effect, unknown/replaced/reverted/orphaned outcomes, duplicate/missed logs, backfill/checkpoint/rollback and idempotent claims |
| Content | Approved catalog/media versions and licenses, safe bounded URI handling, no active metadata execution or arbitrary rule overwrite |
| Target | Effective engine ownership, real wallet account/chain lifecycle, suspend/cold return/duplicate callback, accessibility, logs/privacy and resource cleanup |
| Publication | Fresh policy/channel/region review, contract/admin/signing/payment and store/publication authorizations, actual artifact and independent/human acceptance |

A local EVM configured with chain ID1,8453 or13371 remains a local fixture, not an Ethereum/Base/Immutable deployment. A mock registry is not the managed Immutable operator registry. An adapter simulation can test the game coordinator but cannot certify the adapter's exchange protocol. Preserve those distinctions in test names and reports.

When an expected integration is unavailable, report the exact missing verifier, contract, operator approval, target or tool. Do not choose another provider, relax settlement atomicity, relabel strict locking, suppress a review finding or reset prior operation/approval history to complete the matrix.
