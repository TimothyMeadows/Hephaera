# Presentation ownership and review

Use one full-body presentation owner per rig. The host must suspend/arbitrate the locomotion or MODEL_TO_ANIMATION mixer before action playback writes the same bones. This workflow does not supply upper-body masks, IK, body turning, aim solving or an authoritative ability controller.

Effects bind actual exported anchors. Charge cues follow those anchors. At release, capture the sampled world origin and fly a visual projectile toward the immutable target point copied at action start. Pause uses the same presentation clock. Cancellation, supersession, reset and disposal invalidate old action generations and clean up owned visuals, including when invoked synchronously from event callbacks. Target movement/mutation does not create homing or confirm a hit.

Inspect whole sequences: pose continuity, blend extremes, contact/foot sliding, repeated steps, equipment, release anchor alignment and end pose. Blender cue proxies are technical review aids; verify actual engine effects separately. Test variable frame deltas across boundaries, pause/resume, missing/invalid targets, interruption, repeated actors and lifecycle cleanup. Browser/software rendering does not certify physical GPU timing or another engine's native assets.

Keep authoritative movement, collisions, contacts, damage, resource costs, cooldowns and projectile outcomes in gameplay. Presentation events may inform a host integration, but they are not exactly-once authoritative commands. Source/action selection, independent review and human runtime acceptance remain distinct. Evidence binds current model/package/engine hashes and actual runtime-test, runtime-capture and performance-profile artifacts. No automated report manufactures acceptance or permission to promote.

## THREEJS v2 receiving bridge

Use the [actual Scene API and byte contract](../../../.engine/threejs/actions/README.md). The trusted host's source-export helper executes current native read-only validation. Review mode prepares technical evidence; runtime mode additionally requires current native action, independent and human runtime approval references. Both admit the exact native source export, with its raw model/effect/profile/resource/correspondence bytes. The bridge does not verify promoted/rebound destination bundles or reproduce native closure/promotion algorithms. Source-export verification metadata need not carry the accepted status that native promotion writes separately.

Supply host-decoded, exact reviewed DataTextures/static geometries and actual model/animations loaded from the admitted GLB bytes. Keep one Scene-owned Quarks service and one action scheduler. Its branded claim excludes independent service/underlying-owner updates. Update movement/inputs, advance the shared presentation scheduler once, then use the existing renderer/composer owner. The union of actors, ambient effects, active/draining tails and callback work must fit finite Scene budgets.

For each `[a,b]`, evaluate delivered poses/anchors/endpoints, advance previously active FX through the interval once, then dispatch stable transitions at `b`. Newly created FX receive no earlier time; stopping FX receive the final interval before stopping. Order equal-time actors by stable ASCII ID, then declared transition/identity order. Recheck generations after callbacks. Callback pause or restart discards only that actor's unused update time; another actor and ambient FX still progress. Actor callback failure retires its generation and is reported after unrelated playback finishes the accepted interval.

Actor pause uses owned handles. Follow-action lifetimes freeze; acquired continue-on-scene layers keep independent Scene emission/tail deadlines. New layers start on the actor clock. Preserve the final delivered pose, stop/uncache mixer bindings and release internal/external rig ownership at motion end. Tails read anchors or captured transforms without writing the rig. A new action on that actor retires the old tail generation; cancel/reset/dispose never leave an accidental tail. Declare exceptional-delta, hidden and resume policy without hidden backlog replay.

Every start explicitly chooses `rehearsal` or `host-outcomes`. Rehearsal impacts show the authored fixed point. Host-outcomes suppresses automatic fixed-target impact cues and accepts only reviewed impact cue IDs for a current active/draining generation, once per cue, with fresh non-future Scene time, finite position and normalized world normal. The full authored lifetime must still fit the remaining action envelope. Refusing an expired visual request does not revoke gameplay contact.

Continuous beams sample bounded generation-bound endpoint input at interval end before FX. Require monotonic non-future presentation timestamps, freshness/range and both per-target/aggregate update-rate limits. Missing or invalid input retires the affected presentation. Keep positive uniform anchor/cue scale once, including beam width; world endpoints own beam length. Reset bounded trails at declared teleports/discontinuities.

Receiving reports bind actual module/driver/build/library identities, model/effect/resource closure, renderer, camera and capture settings/artifacts. Exercise real skinned and rigid exports, two actors plus ambient, exact boundaries, tails, pause/cancel/reentrancy, drift/resource failures and teardown. `bindReceiving` only creates a current task-local `pending-native-review` envelope; native validation/acceptance/promotion retain their existing owners. Distinguish CPU/library, actual WebGL, physical GPU, packaged MAUI and human evidence. Unavailable targets remain not-run; reduced emission alone does not establish an authored accessible variant.
